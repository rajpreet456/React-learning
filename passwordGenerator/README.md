# React Password Generator

A simple password generator built while learning React.

## Features
- Adjustable password length
- Include numbers and symbols
- Copy to clipboard using useRef
- Auto password generation

## Tech Stack
- React.js
- JavaScript (ES6+)
- Tailwind CSS

## React Concepts Used
- useState
- useEffect
- useCallback
- useRef

## Learning Goal
To understand React hooks by building real projects.
