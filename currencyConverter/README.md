# Currency Converter App (React)

A simple and responsive Currency Converter built using **React**, **Custom Hooks**, and **Tailwind CSS**.

---

## Features

* Convert between multiple currencies
* Real-time exchange rates using API
* Swap currencies instantly
* Controlled inputs using React state
* Reusable InputBox component
* Clean and responsive UI

---

## Tech Stack

* React (Vite)
* JavaScript (ES6+)
* Tailwind CSS
* Custom Hooks (`useCurrencyInfo`)
* Fetch API

---

## Project Structure

```
src/
 ├── components/
 │    └── InputBox.jsx
 ├── hooks/
 │    └── useCurrencyInfo.js
 ├── App.jsx
 └── main.jsx
```
